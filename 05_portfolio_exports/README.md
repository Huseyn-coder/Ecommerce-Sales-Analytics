# Hesabat səhifələrinin ekran şəkilləri

Power BI hesabatının dörd səhifəsinin ekran görüntüləri. Kök [`README.md`](../README.md) bu fayllara birbaşa istinad edir.

| Fayl | Səhifə | Nə göstərir |
|---|---|---|
| `01_umumi_baxis.png` | Ümumi baxış | KPI-lar, aylıq trend (keçən illə müqayisə), ən çox satan kateqoriya və ştatlar |
| `02_kateqoriyalar.png` | Kateqoriyalar | Kateqoriya üzrə satış, rəy balı və çatdırılma müddəti |
| `03_musteri_catdirilma.png` | Müştəri və çatdırılma | Təkrar alış, gecikmə faizi, ştat üzrə kəsim, ödəniş üsulları |
| `04_dashboard.png` | Dashboard | Bir ekranda ümumi mənzərə və əsas tapıntılar paneli |

Şəkillər hesabatın `is_trend_period` (2017-01 – 2018-08) filtri ilə işləyən cari versiyasından götürülüb; slicer seçimləri təmiz vəziyyətdədir.
